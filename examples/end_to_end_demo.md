# End-to-End Walkthrough Guide (MR-RAG v1.0)

This guide walks you through uploading a PDF, running index tasks, executing retrieval operations, streaming answers, and triggering benchmarks using the Python client scripts in `examples/`.

## Prerequisites
Ensure the serving platform stack is running:
```bash
docker compose up -d --build
```
This starts the Redis broker, Qdrant database, Flask gateway, and task workers.

---

## 1. Upload a Document
Run the [upload.py](file:///Users/kaustavkumar/Kaustav/Projects/task-schedular/examples/upload.py) script to post a document to the server:
```bash
python examples/upload.py backend/test_data/category_A_simple.pdf
```
**Expected Output:**
```
Uploading file: backend/test_data/category_A_simple.pdf to http://localhost:5000/files/upload...
HTTP Status: 201
Upload Successful!
Pipeline ID: 1
File ID: 12
```

---

## 2. Retrieve Context Chunks
To execute hybrid retrieval (Vector, Graph, Entity, Table, Layout) and inspect candidates:
```bash
python examples/retrieve.py "What is the filing date of application?"
```
**Expected Output:**
```
Retrieving context for query: 'What is the filing date of application?'
Pipeline #2 created. Fetching retrieved results...
Retrieved 5 chunks:

[1] Score: 0.942 | Chunk: chunk_p1_n4
Text snippet: The application filing date is recorded as September 14, 2023...
```

---

## 3. Streaming Answers (SSE Chat)
To query the LLM and read output tokens in real-time as they are generated by the model:
```bash
python examples/streaming.py "Summarize the candidate's core expertise."
```
**Expected Output:**
```
Streaming query answer for: 'Summarize the candidate's core expertise.'
Pipeline created: #3. Listening to SSE token stream...

=== STREAMING RESPONSE ===
The candidate exhibits deep expertise in:
1. Distributed systems design (Redis, Docker Compose, worker loops)
2. Document intelligence (OCR fallback parsing, layout extraction)
3. Information retrieval (Qdrant vector stores, multi-hop ensembles)

Stream Finished.
```

---

## 4. Polling for Structured Answers
To chat with standard polling:
```bash
python examples/chat.py "who is Mr. Kaustav Kumar?"
```

---

## 5. Running the Scientific Benchmarks
To trigger the complete multi-baseline quality and latency benchmark suite:
```bash
python examples/benchmark.py
```
This triggers the benchmark, outputs the manifest, and generates regression results.
